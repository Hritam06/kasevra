# Security Policy

## Supported versions

Security fixes will be provided for the latest published KASEVRA release.

Before the first public release, no published release is available.

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities publicly before allowing the maintainers an opportunity to review them.

Use GitHub private vulnerability reporting if it is enabled for the repository. Otherwise, contact the repository maintainers through a private channel.

When reporting, include:
- A description of the suspected vulnerability.
- The affected KASEVRA version or commit.
- Steps to reproduce the issue.
- Relevant logs or proof-of-concept material, with sensitive evidence removed.

Do not include real personal data, confidential evidence, credentials, or other sensitive information in a report.

## Response

Reports will be reviewed as maintainers become available. No fixed response or remediation timeframe is promised.
